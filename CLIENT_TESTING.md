# Cossirae Client Testing Guide

Preview URL on this machine:

`http://localhost:3000/`

## Pages To Review

- Homepage: `http://localhost:3000/`
- Shop: `http://localhost:3000/shop.html`
- Product page: `http://localhost:3000/product.html?slug=abeni-maxi-dress`
- Cart: `http://localhost:3000/cart.html`
- Wishlist: `http://localhost:3000/wishlist.html`
- Customer account: `http://localhost:3000/account.html`
- Admin dashboard: `http://localhost:3000/admin.html`
- 404 page: `http://localhost:3000/404.html`

## What Works In Demo Mode

- Browse site pages
- Search products
- Add products to bag
- Update cart quantity
- Save wishlist items
- View product detail pages by slug
- Use the admin dashboard locally
- Add/edit products locally
- Preview uploaded images and videos locally
- Manage categories locally
- View demo orders and analytics

## What Needs Supabase/Paystack Before Live Production

- Real customer login
- Real admin login and admin roles
- Permanent product image/video upload
- Cloud product database
- Real orders
- Paystack payments
- Paystack webhook verification
- Order confirmation emails
- Live monitoring logs

## Feedback To Collect

- Does the brand feel premium enough?
- Are the categories correct?
- Are product fields complete enough for admin use?
- Is checkout information complete for Nigerian delivery?
- Are there missing pages, policies or content?
- Are there layout issues on mobile?
- Which final photos/videos should replace placeholders?
